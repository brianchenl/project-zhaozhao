# 昭昭计划 Project Zhaozhao

> 日本侵略战争与战后表态的历史资料档案 · The Settled Record

研究范围不限于近代，关注中国及东亚地区的战争、侵略、殖民统治与平民受害，也保留东南亚相关条目。各时代的政权、军队、具体行为与证据分别核对，不把古代记载自动等同于现代法律认定，也不将责任泛化到当代普通日本人。当前已收录内容仍以近现代为主。

将可核查文献整理成事实条目、说法核查和战后表态台账，提供静态 HTML、结构化数据和来源定位。提供简体中文、繁體中文、English、日本語四个版本，每种语言有 5 篇公开条目，尚未覆盖全部历史主题。资料整理与译文采用 AI 辅助，不声称已经过独立专家、双人审核或独立母语审校；译文不是所引文献的官方译本。

## 语言版本

| 语言 | 站点路径 | 条目文件位置 |
| --- | --- | --- |
| 简体中文（原文） | `/` | `src/content/{facts,claims,ledger}/*.md` |
| 繁體中文 | `/zh-hant/` | 各集合的 `zh-hant/` 子目录 |
| English | `/en/` | 各集合的 `en/` 子目录 |
| 日本語 | `/ja/` | 各集合的 `ja/` 子目录 |

页面顶部可切换同一条目的语言。导航、项目说明、引用提示与下载页均已本地化；文献原始题名和馆藏标识可保留原文，便于追溯。译文沿用原文来源链，并记录所依据的原文更新日期。

## 内容结构

- `src/content/facts/`：历史事件、文献与统计。
- `src/content/claims/`：具体命题的核查及证据范围。
- `src/content/ledger/`：战后官方表态及原文出处。
- `templates/`：不参与站点生成的条目模板。
- [内容说明](docs/content-guide.md)：字段、来源独立性和引用格式。

## 本地使用

需要 Node.js 22.12 或更高版本，以及 npm。

```bash
npm ci
npm run dev
npm run verify
```

使用 Astro 静态输出；正文直接存在于 HTML 中，阅读不依赖客户端脚本。锁文件固定依赖版本；`verify` 执行内容校验、测试、类型检查、构建和产物检查。

## 机器可读内容

站点自动从同一组公开条目生成 `/llms.txt`、`/sitemap.xml`、`/data/entries.json` 和 `/data/entries.csv`，避免手工维护索引遗漏。根路径索引和数据包含全部语言；加 `/zh-hant`、`/en`、`/ja` 前缀的文本索引和数据仅含对应语言。JSON schemaVersion 为 2，CSV 增加语言与译文关联字段。`/robots.txt` 声明允许抓取。

JSON-LD 包含 Article / ClaimReview、语言、译文原文关联和出处链接；每个语言页面具有自指 canonical 与互相对应的 hreflang。结构化数据与开放抓取有助于访问和理解，但不保证任何搜索引擎或 AI 产品收录、训练使用或引用率。

## 内容原则

摘要说明结论，正文给出证据与限定。数字附统计口径；更新日期反映实质修订，不为制造新鲜度而刷新。同一文书的译本或镜像不算独立证据，来源数量校验也不代替史料鉴别。

GitHub 源码与站点页面的可见范围不同：未生成网页的草稿仍会存在于源码中，仓库公开后同样可被阅读，历史提交也会保留旧内容。

仓库现已公开。[提交内容勘误](https://github.com/brianchenl/project-zhaozhao/issues/new)时，请注明条目、语言版本、来源及定位，不要上传个人隐私或敏感资料。公开源码不等于独立网站已经上线或已获搜索引擎、AI 收录。
